Hill Motion: Эволюция — релиз v1.0.0
Дата: 31.07.2026

Архив HillMotion_v1.0.0.zip содержит ровно один корневой каталог готового
проекта Godot 4.3. В нём нет .godot, импортного кеша, исходного архива ассетов,
предыдущих релизов или дублированных файлов.

Откройте project.godot в Godot 4.3. Полная инструкция — README.md в архиве.

Проверено статически: GDScript-синтаксис, gdlint, целостность всех res:// ссылок,
отсутствие $Node и :=. В этой среде нет исполняемого Godot 4.3, поэтому живой
запуск редактора честно не заявляется как выполненный.
